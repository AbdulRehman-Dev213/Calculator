# Calculator

A clean, responsive calculator built with **HTML, CSS, and Vanilla JavaScript**. This project focuses on essential arithmetic operations, interactive UI elements, and JavaScript logic, wrapped in a modern dark-themed interface.

## Features

* **Basic Arithmetic:** Perform addition, subtraction, multiplication, and division.
* **Decimal Support:** Enter decimal numbers with duplicate decimal-point prevention.
* **Clear Function:** Reset the calculator and its stored operation.
* **Delete Function:** Remove the last digit from the current input.
* **Error Handling:** Display an error when attempting to divide by zero.
* **Chained Operations:** Continue calculations by selecting another operator.
* **Responsive Layout:** Adapt the calculator layout to different screen sizes.
* **Interactive UI:** Hover effects, styled buttons, and a readable display.

## Technologies Used

* **HTML5** — Structure and calculator keypad.
* **CSS3** — Responsive layout, CSS Grid, custom properties, and hover transitions.
* **JavaScript (ES6+)** — Event listeners, DOM manipulation, functions, and calculation logic.
* **Google Fonts** — Inter, Poppins, and Playfair Display font imports.

## Getting Started

Run the project locally in a few simple steps.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd Calculator
```

### 3. Open the project

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for a convenient development experience.

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.
